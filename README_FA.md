# ⚡️ اسکنر زئوس (Zeus Scanner)

<p align="center">
  <b>زبان / Language:</b> 
  <a href="README.md"><b>English</b></a> | 
  <a href="README_FA.md"><b>فارسی</b></a>
</p>

اسکنر زئوس یک ابزار سریع، مدرن و یکپارچه برای یافتن **آی‌پی‌های تمیز و سالم کلودفلر (Cloudflare Clean IP)** به همراه تست واقعی با هسته قدرتمند **Xray-core** است.

این برنامه اتصال TLS/SNI به لبه‌های کلودفلر را بررسی می‌کند، کاندیداهای برتر را از طریق کانفیگ شخصی شما (VLESS / VMess / Trojan) در یک تونل واقعی محک می‌زند و سرعت دانلود واقعی را از داخل تونل اندازه‌گیری می‌نماید.

---

### 🌟 امکانات و تغییرات جدید (نسخه ۱.۶)
- **🌐 نمونه‌بردار تصادفی آفلاین (Offline Cloudflare CIDR Sampler):** تولید نمونه‌های تصادفی معتبر از میان بیش از ۱.۵ میلیون آی‌پی در ۱۵ ساب‌نت رسمی کلودفلر (`104.16.0.0/13`، `172.64.0.0/13`، `162.158.0.0/15` و...)؛ کاملاً آفلاین، در کسری از ثانیه و بدون هیچ‌گونه وابستگی به سایت‌های خارجی یا خطر مسدود شدن.
- **🎯 فیلد SNI کاملاً اختیاری و هوشمند:** وارد کردن آدرس پنل یا ورکر اختیاری شد! اگر کانفیگ پیست کنید خودکار استخراج می‌شود و اگر کادر خالی بماند از `cloudflare.com` استفاده می‌گردد تا اسکن بلافاصله بدون توقف انجام شود.
- **🔄 مخازن چندگانه آنلاین با پشتیبان محلی:** دریافت آی‌پی‌های تمیز اپراتورها (همراه اول، ایرانسل، رایتل، مخابرات، شاتل و...) با استفاده از سرورهای آینه‌ای پرسرعت jsDelivr و گیت‌هاب، به‌همراه پایگاه‌داده آفلاین توکار در صورت قطعی کامل اینترنت.
- **🔔 اعلان صوتی ملایم و وب‌نوتیفیکیشن دسکتاپ:** پخش ملودی گوش‌نواز و ارسال نوتیفیکیشن سیستمی مرورگر به محض پایان اسکن، تا در اسکن‌های طولانی نیازی به چک کردن مداوم صفحه نداشته باشید.

## 🚀 راهنمای نصب و اجرا

### 💻 ویندوز (Windows)
**پیش‌نیاز:** فقط پایتون ۳ روی سیستم نصب باشد.

1. پروژه را دانلود کرده و از حالت فشرده خارج کنید.
2. ترمینال (PowerShell یا CMD) را در پوشه پروژه باز کنید و دستور زیر را اجرا کنید:
   ```cmd
   python server.py
   ```
3. مرورگر شما به‌صورت خودکار باز خواهد شد. در غیر این صورت به آدرس زیر بروید:
   ```text
   http://127.0.0.1:8000/
   ```

*(نکته: فایل باینری هسته Xray در پوشه `bin` ویندوز موجود است و نیازی به نصب هیچ پیش‌نیاز دیگری ندارید.)*

---

### 📱 اندروید (Termux) و لینوکس
برای نصب خودکار و اجرای یک‌خطی در لینوکس یا محیط Termux اندروید، دستور زیر را اجرا کنید:
```bash
curl -fsSL https://raw.githubusercontent.com/panel-zeus/IP-scanner/main/install.sh | bash
```
پس از اتمام نصب، هر زمان که بخواهید می‌توانید با دستور زیر اسکنر را اجرا کنید:
```bash
zeus
```
مرورگر به‌صورت خودکار آدرس `http://127.0.0.1:8000/` را باز خواهد کرد.

## 🧠 مراحل و نحوه کارکرد برنامه

### ۱. کشف اولیه (Discovery)
اسکنر ابتدا با هندشیک TLS روی پورت‌های انتخاب‌شده (۴۴۳، ۲۰۵۳، ۲۰۸۳، ۲۰۸۷، ۲۰۹۶، ۸۴۴۳) همراه با SNI پنل شما ارتباط برقرار می‌کند.

### ۲. اعتبارسنجی پاسخ کلودفلر (HTTP Verification)
پاسخ دریافتی باید دارای هدرهای مخصوص کلودفلر (`cf-ray` یا `Server: cloudflare`) باشد. در صورتی که پاسخ حاوی کدهای ۴۰۳، ۴۰۹ یا ۴۲۹ باشد، نشان‌دهنده مسدود بودن دسترسی برای آن SNI بوده و آی‌پی رد می‌شود.

### ۳. غربالگری هوشمند (Funnel Screening)
برای لیست‌های بزرگ (تا ۱۰۰۰ آی‌پی)، ابتدا یک تست سریع انجام می‌شود تا بهترین کاندیداها بدون فوت وقت شناسایی شوند. سپس تست‌های دقیق فقط روی کاندیداهای منتخب متمرکز می‌شوند.

### ۴. اندازه‌گیری دقیق تاخیر و پایداری
میانه پینگ (Median Ping)، انحراف معیار (Jitter/Stability) و درصد گم‌شدن بسته‌ها (Packet Loss) در چند تکرار محاسبه می‌شوند.

### ۵. تست واقعی با هسته Xray
برای آی‌پی‌های با بالاترین امتیاز، یک فرآیند محلی Xray ایجاد شده و یک درخواست واقعی `generate_204` از درون تونل ارسال می‌شود. دریافت پاسخ موفق، عملکرد صد درصدی کانفیگ روی آن آی‌پی را تضمین می‌کند.

### ۶. تست سرعت دانلود (Real Speed Test)
در صورت روشن بودن گزینه «تست سرعت»، یک تست دانلود چند مگابایتی واقعی از سرورهای کلودفلر از داخل تونل انجام شده و پهنای باند بر حسب KB/s یا MB/s گزارش داده می‌شود.

## 📋 نحوه استفاده از آی‌پی‌های سالم در فیلترشکن‌ها

پس از پایان اسکن:
1. روی دکمه **«کپی آی‌پی‌های سالم»** کلیک کنید (یا روی هر ردیف دلخواه بزنید تا آدرس آن کپی شود).
2. وارد نرم‌افزار کلاینت خود شوید (**v2rayN**، **v2rayNG**، **Hiddify**، **Nekoray**، **Streisand** و...):
   - کانفیگ مورد نظر را باز کرده و آن را ویرایش (**Edit**) کنید.
   - مقدار فیلد **Address** (یا آدرس سرور / IP) را با **آی‌پی سالم پیدا شده** جایگزین کنید.
   - **توجه بسیار مهم:** مقادیر فیلدهای **SNI** و **Host** نباید تغییر کنند و باید همان دامنه اصلی شما باقی بمانند.
3. کانفیگ را ذخیره کرده و متصل شوید.

## 📂 ساختار فایل‌های پروژه

| فایل | توضیحات |
|---|---|
| `index.html` | رابط کاربری پیشرفته، نمونه‌بردار آفلاین کلودفلر و سیستم اعلان |
| `server.py` | هسته مرکزی اسکن شبکه و وب‌سرور API محلی |
| `xray.py` | مدیریت هسته Xray، تجزیه لینک‌های کانفیگ، ساخت تونل و تست سرعت |
| `install.sh` | اسکریپت نصب و راه‌اندازی خودکار برای لینوکس و Termux |
| `test_core.py` | تست‌های واحد (Unit Tests) برای تضمین صحت عملکرد کدها |
| `bin/` | حاوی باینری هسته رسمی Xray و فایل‌های کمکی |

---

## ⚙️ متغیرهای محیطی (Environment Variables)

| متغیر | مقدار پیش‌فرض | توضیحات |
|---|---|---|
| `ZEUS_PORT` | `8000` | پورت وب‌سرور داشبورد |
| `ZEUS_BIND` | `127.0.0.1` | آدرس گوش دادن وب‌سرور |
| `XRAY_BIN` | `./bin/xray` | مسیر فایل باینری هسته Xray |
| `ZEUS_DIR` | `~/zeus-scanner` | مسیر نصب در لینوکس / اندروید |
| `ZEUS_XRAY_TAG` | `latest` | نسخه هسته Xray برای دانلود خودکار |
